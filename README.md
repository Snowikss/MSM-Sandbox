# MSM Sandbox

Локальная тестовая песочница для экспериментов с серверной логикой в стиле My Singing Monsters.

> Проект предназначен для локальной/частной тестовой среды. Он не подключается к официальным серверам Big Blue Bubble, не использует основной игровой аккаунт и не предназначен для обхода защиты официального сервиса.

## MVP

Первая версия даёт нам собственную модель мира и API для:

- тестового профиля;
- Plant Island;
- монет, алмазов и еды;
- добавления и удаления тестовых монстров;
- изменения уровня монстра;
- переключения скорости таймеров (`x1`, `x10`, `instant`);
- сохранения состояния в локальный JSON;
- простой веб-панели администратора.

## Запуск

Требуется Python 3.11+.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

После запуска:

- панель: `http://127.0.0.1:8000/`
- API: `http://127.0.0.1:8000/api/state`
- Swagger: `http://127.0.0.1:8000/docs`

## Что дальше

Когда базовый sandbox стабильно запускается, следующим слоем можно делать адаптер под конкретный тестовый клиент. Серверное ядро при этом останется отдельным, чтобы не связывать всю разработку с одной версией клиента.
